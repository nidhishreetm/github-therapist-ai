# 🧑‍💻 GitHub Repo Therapist AI

An AI agent that analyzes GitHub repositories like a therapist analyzing behavior.

## 💡 What it does
- Analyzes repo habits (commits, structure, naming)
- Detects developer behavior patterns
- Gives a "Diagnosis" and "Treatment Plan"

## 🧠 Personality
This agent is slightly sarcastic, insightful, and helpful — like a therapist for developers.

## ⚙️ Example Input
No README, commits once a week, files named final_v2

## 📊 Example Output

Diagnosis:
- Inconsistent workflow
- Avoidance of documentation

Treatment Plan:
- Add a README
- Commit daily
- Use clear file names

Observation:
You name files like you're hiding evidence.
